우리 반 파이트 온라인 버전

중요: index.html 파일을 컴퓨터에서 직접 더블클릭하면 온라인 연결이 되지 않습니다.
서버와 함께 실행하거나 온라인 호스팅에 배포한 홈페이지 주소로 접속해야 합니다.

내 컴퓨터에서 시험하기:
1. Node.js 설치: https://nodejs.org
2. 이 폴더에서 터미널을 엽니다.
3. npm install
4. npm start
5. 브라우저에서 http://localhost:3000 접속

친구들과 서로 다른 기기에서 하려면 이 폴더 전체를 Node.js 서버 호스팅(Render 등)에 배포해야 합니다.
HTML 파일만 따로 올리는 정적 호스팅은 실시간 멀티플레이를 지원하지 않습니다.

관리자:
- 게임 방에 입장한 다음 '관리자 메뉴'를 엽니다.
- #password 입력 후 '관리자 로그인'을 누릅니다.
- 승리 횟수 변경 대상과 숫자를 선택하고 '승리 횟수 적용'을 누릅니다.
- 모두 체력 회복, 경기·승리 기록 초기화도 가능합니다.

기본 관리자 비밀번호: password
실제 공개 전에 server.js의 ADMIN_PASSWORD 환경변수를 다른 비밀번호로 바꾸는 것을 권장합니다.
