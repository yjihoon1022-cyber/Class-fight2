우리 반 파이트 게임 - 실행 방법

1. Node.js를 설치합니다. (https://nodejs.org)
2. 압축을 푼 폴더에서 터미널/명령 프롬프트를 엽니다.
3. 아래 명령어를 차례로 실행합니다.

   npm install
   npm start

4. 브라우저에서 http://localhost:3000 을 엽니다.
5. 한 명은 '새 방 만들기'를 누르고, 다른 친구는 방 코드를 입력해 참가합니다.

여러 컴퓨터에서 접속하려면:
- 서버를 실행한 컴퓨터와 같은 와이파이에 연결한 뒤, 서버 컴퓨터의 내부 IP 주소로 접속하거나
- Node.js를 지원하는 호스팅 서비스에 이 프로젝트를 배포해야 합니다.
- localhost 주소는 서버를 실행한 컴퓨터에서만 열립니다.

관리자:
- 관리자 메뉴를 열고 #password 를 입력한 뒤 로그인합니다.
- 경기 초기화 / 모두 체력 회복 기능을 사용할 수 있습니다.
- 비밀번호를 바꾸려면 실행 전에 환경변수 ADMIN_PASSWORD를 설정하세요.
  macOS/Linux: ADMIN_PASSWORD=새비밀번호 npm start
  Windows PowerShell: $env:ADMIN_PASSWORD="새비밀번호"; npm start

게임 규칙:
- 두 명이 한 방에서 대결합니다.
- 주사위 숫자(1~6)를 굴린 뒤 공격 버튼을 누르면 그 숫자만큼 상대 체력이 줄어듭니다.
- 상대 체력이 0이 되면 승리합니다.
